급여대장 자동 변환 — 일괄 처리 (Windows 실행 안내)
==========================================

1. 이 폴더 전체를 로컬 드라이브에 압축 해제한 상태로 둡니다.
2. PayrollAutomation_Maumson&Care24.exe를 실행합니다.

기본 사용법
----------
1. "위하고 양식 폴더 업데이트"를 눌러 사업장을 일괄 등록/갱신합니다.
   (기본 대상 폴더: 바탕화면\작업파일\Wehago — 이 폴더 안의 위하고
   양식 파일들을 스캔해서 사업장명으로 자동 등록합니다. 이 폴더가 없으면
   실행 전에 준비해두세요.)
2. "급여대장 추가 (여러 개 선택 가능)"로 이번 달 원본 급여대장 파일을
   올립니다. 파일명/사원 명부로 등록된 사업장을 자동 인식해서 바로
   처리합니다.
3. 자동 인식이 안 된 항목은 목록에서 "위하고 파일 선택"으로 직접
   지정할 수 있습니다.
4. 결과를 검토하고("이 파일 다운로드" 전 화면에서 금액 직접 수정 가능),
   맞지 않는 항목매핑은 "검증결과 보기"에서 직접 매칭을 골라 적용합니다.
5. "선택 항목 다운로드" 또는 "전체 다운로드"로 위하고 업로드용 파일을
   내려받습니다.

"사업장 관리"에서 등록된 사업장 목록과 위하고 참고파일 경로를 확인/수정할
수 있습니다.

중요
----
- PayrollAutomation_Maumson&Care24.exe 파일만 따로 옮기면 실행되지 않습니다.
  이 폴더 안의 모든 파일을 함께 유지해야 합니다.
- 사업장 등록 정보(SQLite DB, 수동으로 고친 항목매칭 포함)는
  _internal\data\registry.db에 저장됩니다. 빌드 시점에 기존
  등록 내용을 그대로 포함해서 배포하므로 처음부터 다시 등록할
  필요는 없습니다 — 이후 앱을 쓰면서 새로 등록/수정한 내용은
  이 배포본의 _internal\data\ 안에만 쌓입니다(다음에 새로 빌드할
  때 반영하려면 이 폴더의 data\를 프로젝트 data\로 다시 복사해와야
  합니다).
- 입력 파일 형식은 .xlsx/.xlsm입니다. .hwp는 아직 처리 흐름에
  연결되지 않았습니다.
- Windows SmartScreen 경고가 표시될 수 있습니다. 코드 서명 인증서가
  없는 프로그램에서 보일 수 있는 일반적인 경고입니다.
- 실행 중 예기치 않게 종료된다면 캡처된 오류 메시지와 함께 알려주세요.
